# A whole neighborhood is safe at two-thirds

**Claim.** Start at any original §4 matrix with real K≥6. Change **each of the 36 entries independently** by any real amount of absolute value strictly less than 1/3, in the units of that table. At least one complete allocation is both 2/3-EFX and Pareto optimal. Values remain positive since the original minimum is 1. This is an absolute bound, not a percentage, nor a neighborhood of every positive valuation matrix.

To prove existence we need not predict which allocation remains efficient after ties break. Fix the anchor `A=(xb,y,cdpq,ae)`. Among the allocations weakly improving on A at the changed valuations, choose one maximizing the sum of the changed utilities. This finite set contains A; its maximizer is globally Pareto optimal by transitivity. We certify that **every** member of the set is still fair enough.

For agent i, let d be the original value of a proposed bundle S minus the original value of Aᵢ. Perturbing the entries changes that difference by strictly less than `|S △ Aᵢ|/3` when the two bundles differ: shared goods cancel. Thus S can weakly improve only if `3d+|S △ Aᵢ|>0`, or S=Aᵢ. The checker compares each possible S symbolically over all K≥6 (d is affine in K at the center) and enumerates disjoint choices that exhaust the goods. Relaxing the test to allow a different K for each agent leaves **only two** allocations: A and `(xb,y,cepq,ad)`. They differ only in which of agents 3 and 4 gets `d` or `e`.

For each of these allocations and every trimmed comparison bundle R of another agent, check `9vᵢ(S)−6vᵢ(R) ≥ 3|S|+2|R|` at the original valuations. These are affine inequalities checked on the full half-line. They imply `3v′ᵢ(S) ≥ 2v′ᵢ(R)` at the changed valuations: after multiplying by three, the worst possible drop in that margin is at most `3|S|+2|R|`. Thus whichever allocation is efficient suffices. The [checker](check.py) tests the actual comparisons; the [receipt](RECEIPT.json) records the survivor count.

**Why the strict radius matters.** At movement exactly 1/3 there can be a third weak dominator. Change only agent 3's value of `e` by +1/3 and of `d,q` by −1/3. The reassignment `(xbq,y,cep,ad)` then leaves agent 3 indifferent to `cdpq`, leaves agents 2 and 4 indifferent, and gives agent 1 an extra good. This refutes extending the two-allocation argument to the closed boundary; it does **not** refute fairness there.
